# 정통 판타지 RPG 디스코드 봇

디스코드에서 즐길 수 있는 정통 판타지 RPG 게임 봇입니다. 캐릭터를 생성하고, 몬스터와 전투하며, 아이템을 수집하고 레벨업할 수 있습니다.

## 기능

### 🎭 캐릭터 시스템
- **4가지 클래스**: 전사, 마법사, 궁수, 도적
- **능력치**: HP, MP, 공격력, 방어력, 속도
- **레벨업 시스템**: 경험치 획득 후 레벨업 시 능력치 자동 증가
- **고유 스킬**: 각 클래스별 3개의 특수 스킬

### ⚔️ 전투 시스템
- **턴제 전투**: 플레이어와 적이 번갈아 가며 행동
- **다양한 행동**: 기본 공격, 스킬 사용, 방어, 도망
- **다양한 몬스터**: 슬라임, 고블린, 오크, 드래곤 등 7종류
- **레벨 기반 적 생성**: 플레이어 레벨에 맞는 적 자동 생성
- **전투 보상**: 경험치와 골드 획득

### 🎒 아이템 시스템
- **다양한 아이템**: 무기, 방어구, 포션, 재료
- **인벤토리**: 최대 20슬롯
- **장착 시스템**: 무기, 방어구 장착으로 능력치 증가
- **상점 시스템**: 아이템 구매 기능
- **소비 아이템**: HP/MP 포션 사용

### 💾 데이터 저장
- **JSON 데이터베이스**: 캐릭터, 인벤토리 정보 자동 저장
- **자동 저장**: 모든 변경사항 즉시 저장

## 설치 방법

### 1. 필수 요구사항
- Python 3.8 이상
- pip (Python 패키지 관리자)

### 2. 디스코드 봇 생성
1. [Discord Developer Portal](https://discord.com/developers/applications)로 이동
2. "New Application" 클릭하여 새 애플리케이션 생성
3. "Bot" 탭에서 "Add Bot" 클릭
4. "TOKEN" 섹션에서 "Reset Token" 클릭 후 토큰 복사
5. "Privileged Gateway Intents"에서 다음 권한 활성화:
   - Message Content Intent
   - Server Members Intent
6. "OAuth2" > "URL Generator"에서 bot 권한 추가:
   - Send Messages
   - Read Message History
   - Use Slash Commands
7. 생성된 URL로 봇을 서버에 초대

### 3. 프로젝트 설치
```bash
# 프로젝트 디렉토리로 이동
cd fantasy-rpg-bot

# 필요 패키지 설치
pip install -r requirements.txt
```

### 4. 설정 파일 수정
`config.py` 파일에서 디스코드 봇 토큰을 설정하세요:

```python
DISCORD_TOKEN = 'YOUR_BOT_TOKEN_HERE'  # 여기에 복사한 토큰을 붙여넣으세요
```

## 실행 방법


## 명령어 목록

### 캐릭터 관리
- `!캐릭터생성 [이름] [클래스]` - 새로운 캐릭터 생성
  - 클래스: 전사, 마법사, 궁수, 도적
  - 예: `!캐릭터생성 영웅 전사`
- `!내정보` - 내 캐릭터 정보 확인

### 전투
- `!전투시작` - 전투 시작
- `!공격` - 기본 공격
- `!스킬 [스킬명]` - 스킬 사용
  - 예: `!스킬 파이어볼`
- `!방어` - 방어 태세 (HP 5 회복)
- `!도망` - 전투 도망 (50% 확률)
- `!회복` - 캐릭터 회복 (골드 필요)

### 아이템
- `!인벤토리` - 인벤토리 확인
- `!상점` - 상점 목록 확인
- `!구매 [아이템ID]` - 아이템 구매
  - 예: `!구매 potion_hp_small`
- `!사용 [아이템ID]` - 소비 아이템 사용
  - 예: `!사용 potion_hp_small`
- `!장착 [아이템ID]` - 장비 장착
  - 예: `!장착 sword_iron`

### 기타
- `!도움말` - 도움말 표시

## 클래스 정보

### 전사
- **특징**: 높은 체력과 방어력
- **기본 능력치**: HP 150, MP 30, 공격력 15, 방어력 10, 속도 8
- **스킬**: 파워 스트라이크, 방어 태세, 분노의 일격

### 마법사
- **특징**: 높은 마력과 공격력
- **기본 능력치**: HP 80, MP 100, 공격력 20, 방어력 3, 속도 10
- **스킬**: 파이어볼, 아이스 스파이크, 라이트닝 볼트

### 궁수
- **특징**: 높은 속도와 정확도
- **기본 능력치**: HP 100, MP 50, 공격력 18, 방어력 5, 속도 15
- **스킬**: 관통 사격, 연사, 맹독 화살

### 도적
- **특징**: 높은 속도와 치명타 확률
- **기본 능력치**: HP 90, MP 60, 공격력 16, 방어력 4, 속도 18
- **스킬**: 암습, 백스탭, 은신

## 게임 플레이 가이드

### 시작하기
1. `!캐릭터생성 [이름] [클래스]`로 캐릭터 생성
2. `!내정보`로 캐릭터 정보 확인
3. `!전투시작`으로 첫 전투 시작

### 전투 팁
- 낮은 레벨에서는 기본 공격이 효율적입니다
- MP가 부족할 때는 방어 태세를 사용하세요
- 위험한 상황에서는 도망을 고려하세요
- 스킬은 강력하지만 MP를 많이 소모합니다

### 성장 팁
- 꾸준히 전투하여 레벨업하세요
- 상점에서 좋은 장비를 구매하세요
- HP/MP 포션을 항상 준비하세요
- 자신의 클래스에 맞는 장비를 선택하세요

## 문제 해결

### 봇이 연결되지 않을 때
1. config.py에서 토큰이 올바른지 확인
2. Discord Developer Portal에서 봇이 활성화되어 있는지 확인
3. 인텐트 권한이 올바르게 설정되어 있는지 확인

### 명령어가 작동하지 않을 때
1. 봇에게 sufficient 권한이 있는지 확인
2. 명령어 접두사(!)를 올바르게 사용했는지 확인
3. 캐릭터가 생성되어 있는지 확인

### 데이터가 저장되지 않을 때
1. data.json 파일이 존재하는지 확인
2. 파일 쓰기 권한이 있는지 확인
3. 디스크 공간이 충분한지 확인
