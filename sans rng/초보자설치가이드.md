# 🎮 로블록스 샌즈 RNG 게임 - 초보자 설치 가이드

## 📋 준비물
- 로블록스 스튜디오 (무료 다운로드 가능)
- 인터넷 연결
- 이 가이드 파일들

---

## 🚀 1단계: 로블록스 스튜디오 설치

1. [로블록스 스튜디오 다운로드](https://create.roblox.com/) 방문
2. "Start Creating" 버튼 클릭
3. 로블록스 계정으로 로그인 (없으면 무료로 가입)
4. Studio 다운로드 및 설치

---

## 🎯 2단계: 새 게임 만들기

1. 로블록스 스튜디오 실행
2. "New" 탭 클릭
3. "Baseplate" 템플릿 선택
4. 게임 이름을 "SansRNGGame"으로 설정
5. "Create" 버튼 클릭

---

## 📁 3단계: 파일 배치 (가장 중요!)

### 📂 ReplicatedStorage 설정
1. 왼쪽 Explorer에서 **ReplicatedStorage** 찾기
2. ReplicatedStorage를 오른쪽 클릭 → **Insert Object** → **Folder**
3. 폴더 이름을 **SansRNGGame**으로 변경
4. SansRNGGame 폴더 안에 다음 파일들을 추가:

#### 📄 ReplicatedStorage/SansRNGGame/ 안에 넣을 파일:
- **GameConfig.lua** (ModuleScript)
- **UISystem.lua** (LocalScript)

### 📂 ServerScriptService 설정
1. 왼쪽 Explorer에서 **ServerScriptService** 찾기
2. ServerScriptService를 오른쪽 클릭 → **Insert Object** → **Folder**
3. 폴더 이름을 **SansRNGGame**으로 변경
4. SansRNGGame 폴더 안에 다음 파일들을 추가:

#### 📄 ServerScriptService/SansRNGGame/ 안에 넣을 파일:
- **MainGameScript.lua** (Script)
- **WeaponSystem.lua** (Script)
- **CurrencySystem.lua** (Script)
- **InventorySystem.lua** (Script)
- **RaritySystem.lua** (ModuleScript)

---

## 🔧 4단계: 스크립트 파일 만들기

### 스크립트 파일 생성 방법:
1. 폴더를 오른쪽 클릭
2. **Insert Object** 클릭
3. **Script** 또는 **ModuleScript** 또는 **LocalScript** 선택
4. 파일 이름 변경 (예: GameConfig)

### 스크립트 타입 확인:
- **GameConfig.lua**: ModuleScript
- **RaritySystem.lua**: ModuleScript
- **UISystem.lua**: LocalScript
- **나머지 파일들**: Script

---

## 📝 5단계: 코드 붙여넣기

### 각 파일에 코드 붙여넣기:
1. 만든 스크립트 파일을 더블 클릭
2. 코드 편집기가 열림
3. 이 폴더에 있는 같은 이름의 .lua 파일 내용 복사
4. 코드 편집기에 붙여넣기
5. Ctrl+S (저장)

### 예시:
- `GameConfig.lua` 파일을 열면 `GameConfig.lua` 코드 내용을 복사해서 붙여넣기
- `MainGameScript.lua` 파일을 열면 `MainGameScript.lua` 코드 내용을 복사해서 붙여넣기

---

## 🌐 6단계: RemoteEvents/Functions 만들기

### ReplicatedStorage에 직접 추가:
1. **ReplicatedStorage**를 오른쪽 클릭
2. **Insert Object** → **RemoteEvent**
3. 이름을 **SansCaughtEvent**로 변경
4. 같은 방법으로 다음 것들도 추가:
   - CurrencyChangedEvent (RemoteEvent)
   - InventoryChangedEvent (RemoteEvent)
   - CompendiumChangedEvent (RemoteEvent)
   - OpenWeaponShop (RemoteEvent)
   - GetCurrency (RemoteFunction)
   - GetInventory (RemoteFunction)
   - GetCompendium (RemoteFunction)
   - SellItem (RemoteEvent)

---

## 🗺️ 7단계: 맵 만들기

### 간단한 맵 생성:
1. **Workspace**를 오른쪽 클릭
2. **Insert Object** → **Part**
3. Part 이름을 **GameFloor**로 변경
4. Properties에서:
   - Size: (200, 1, 200)
   - Position: (0, 0, 0)
   - Anchored: 체크
   - Color: 회색

---

## ▶️ 8단계: 게임 테스트

1. 상단 메뉴에서 **Play** 버튼 클릭 (또는 F5)
2. 게임이 시작되면 샌즈들이 스폰되는지 확인
3. 샌즈를 클릭해서 잡을 수 있는지 확인
4. 상단에 UI가 표시되는지 확인
5. **Stop** 버튼으로 테스트 종료

---

## ❗ 자주 하는 실수

### ❌ 스크립트 타입 틀리기
- **ModuleScript**: GameConfig, RaritySystem
- **LocalScript**: UISystem
- **Script**: 나머지 모두

### ❌ 파일 위치 틀리기
- **ReplicatedStorage**: GameConfig, UISystem
- **ServerScriptService**: 나머지 모두

### ❌ RemoteEvent/Function 빼먹기
- ReplicatedStorage에 모두 추가해야 함

---

## 🔍 문제 해결

### 게임이 작동하지 않을 때:
1. **Output** 창 확인 (View → Output)
2. 빨간색 에러 메시지 확인
3. 스크립트 타입이 올바른지 확인
4. 파일 위치가 올바른지 확인

### 샌즈가 스폰되지 않을 때:
1. MainGameScript가 ServerScriptService에 있는지 확인
2. GameConfig가 ReplicatedStorage에 있는지 확인
3. 맵에 바닥이 있는지 확인

### UI가 표시되지 않을 때:
1. UISystem이 LocalScript인지 확인
2. ReplicatedStorage에 있는지 확인
3. StarterGui에 있는지 확인
